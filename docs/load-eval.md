# Загрузка игры на мобильном (замер)

Стенд: собранная версия за локальным сервером с ограничением скорости (без сжатия, холодный кеш), окно 375×812, Chrome из приложения.
Метка «главный экран готов» = когда загружены основной скрипт, стили, шрифты и картинки главного экрана.

| Сеть | Было | Стало |
|---|---|---|
| 20 Мбит/с | 0,70 с | 0,58 с |
| 1,6 Мбит/с, 150 мс (медленный 4G) | 7,0 с, до этого скачано 3,2 МБ | 2,8 с, скачано 0,73 МБ |
| 0,4 Мбит/с, 400 мс (3G) | 14,5 с | 10,0 с (основной скрипт 295 КБ без сжатия качается ~7 с) |

Что изменено:
- заставка `index.html` с полоской показывается сразу, до загрузки скрипта;
- загрузка по ступеням (`src/ui/boot.ts`): основа главного экрана → заставка «Загружаем игру», если дольше 0,35 с; затем в простое иконки, звуки (по 4 файла за раз, низкий приоритет) и музыка; модели распознавания стартуют после этого;
- питомцы на главной не качают 4 лишних анимации ожидания (только «грустную»): 560 КБ вместо ~2 МБ; запускаются по одному-два;
- статистика загрузки: `src/ui/loadstats.ts`: плашка по адресу `?stats`, таблица в консоли, последние 20 запусков в localStorage `pq-load-log`.
Ограничение: процессор не ограничивался (в приложении нет такой возможности), поэтому разбор скриптов и Lottie на слабом телефоне замерен только косвенно.
