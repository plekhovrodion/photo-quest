# Замер распознавания CLIP

Набор: 342 фото из Wikimedia Commons (категории вроде Spoons, Bananas), 48 предметов игры, по 6–8 фото на предмет.
Метрики: «узнано» — сколько фото засчитано для своего предмета; «путаница» — как часто засчитывается чужое задание **того же места** (ложка вместо вилки).
Фото берутся из интернета, а не снимаются ребёнком дома, поэтому цифры ориентировочные; для сравнения вариантов между собой они подходят.

| Вариант | Узнано | Путаница |
|---|---|---|
| было: одна фраза, правило «в первых двух» | 76,6% | 5,2% |
| + ансамбль из 8 фраз | 78,7% | 5,4% |
| + «фон» (пустая комната, рука, стена…) | 78,1% | 4,9% |
| + несколько вырезов кадра | 78,1% | 5,0% (медленнее в 2–4 раза, не включено) |
| **выбрано: ансамбль + фон + порог вероятности 0,02** | **87,7%** | **10,1%** |
| прежнее правило «в первых шести» (зона «возможно») | 88,3% | 19,7% |

Вывод: правило по вероятности (softmax с масштабом 100 по всем предметам и «фону») узнаёт столько же, сколько «первые шесть», но путает соседние задания вдвое реже.
Порог 0,05 даёт 81,9% / 5,5%, порог 0,03 — 85,8% / 8,0%; значение можно менять в `CLIP_ACCEPT` (`src/vision/clip.ts`).

Сквозная проверка (MobileNet + COCO + CLIP) на 18 трудных предметах по 8 фото: засчитано 121 из 144 (84%).

Пересобрать описания: `node scripts/build-clip.mjs`.

## Замер на реальных размеченных фото (COCO val2017)
759 объектов 43 классов, предмет занимает от 4% кадра, кадры — обычные бытовые сцены с беспорядком (кухни, комнаты, улицы).
Порог засчитывания 0,02; «путаница» — засчитано чужое задание того же места (если этот предмет не был на фото).
Скрипты: `scripts/eval-coco/`.

| Режим | Узнано | Путаница |
|---|---|---|
| весь кадр, центр (как сейчас без рамки) | 75,2% | 8,4% |
| YOLOv8n: рамка ближе к центру | 64,6% | 8,4% |
| YOLOv8n: 3 лучшие рамки | 86,6% | 18,3% |
| весь кадр + 3 рамки YOLOv8n | 91,6% | 20,9% |
| то же, порог 0,08 | 82,6% | 8,8% |
| идеальная вырезка по разметке (потолок) | 91,8% | 9,0% |

При одинаковой путанице (~8,5%) рамки YOLO дают +7 пунктов (75,2% → 82,6%). Сильнее всего выигрывают мелкие предметы в беспорядке:
вилка 3→16 из 18, чашка 4→16, бутылка 4→15, ложка 5→12, растение 4→12, стул 7→15, машина 9→17, книга 8→11.
Рамка YOLO попадает в нужный предмет (IoU>0,4) в 62,6% случаев; идеальная вырезка пока лучше, значит есть куда расти.

Оговорка: набор состоит из классов COCO, на которых обучен YOLOv8n, поэтому для него условия лучше, чем для предметов вне COCO
(полотенце, носок, обувь, ручка, ластик, цветы, грибы). Для них рамок YOLO не будет, там по-прежнему работает кадр целиком.
