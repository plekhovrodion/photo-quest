# Замер узнавания на LVIS (боевой конвейер игры)

Набор: LVIS v1 val (разметка 1203 категорий на фото COCO), 3913 фото, из них положительных пар «фото × задание» 7107.
Модели и пороги те же, что в игре: COCO-SSD lite_mobilenet_v2 (порог 0,3, слова из `tasks.ts`) и CLIP ViT-B/32 (порог 0,02 от вероятности по всем 104 меткам).
Прогон шёл в браузере через настоящие модули игры. «Игра» = COCO ИЛИ CLIP (как `evaluate()`). Размер предмета = доля кадра под самой большой рамкой.
Отрицательные примеры: фото, где LVIS подтверждает отсутствие категории (не размечена и не в `not_exhaustive`), всего 271 659 пар.

## Итоги
- Крупные предметы (≥8% кадра, так снимает ребёнок): макро по 72 заданиям COCO 62%, CLIP 77%, **игра 86%**; микро по 2205 фото **90,3%**.
- Все размеры (≥0,3% кадра): игра 62% (макро), мелкие (<3%) 48%.
- Ложное засчитывание (предмета на фото нет): COCO 0,5%, CLIP 2,9%, игра **3,2%** на пару фото×задание.
- Только COCO (слабое устройство без CLIP): у COCO-SSD есть класс примерно для 44 из 74 заданий; крупные предметы с классом COCO узнаются в среднем 62–95%.
- Порог CLIP (крупные / ложные): 0,01 → 92,2% / 5,1%; **0,02 → 90,3% / 3,2%**; 0,04 → 88,5% / 2,0%; 0,08 → 86,6% / 1,3%; 0,15 → 84,6% / 1,0%.

## Оговорки
- LVIS размечена неполно: часть «ложных» засчитываний может быть настоящим предметом без метки. Это занижает точность.
- Для новых предметов (чайник, гитара, глобус, калькулятор, ластик, пенал, шампунь, расчёска, зубная паста, сапоги, шлем, перчатки, яйцо, помидор) в LVIS почти нет крупных кадров (N от 0 до 6), цифры по ним ненадёжны. Их проверяли отдельно на чистых фото Wikimedia (по 10 на предмет): 8–10 из 10, кроме картины 7, яйца 9.
- Нет в LVIS: клей, линейка, уточка-игрушка, сыр, картина (рамка), есть только «painting».
- Мелкие предметы (<3% кадра) узнаются плохо, ребёнка надо учить подносить предмет ближе (подсказка в игре).

## После отключения слабых заданий
Отключены (в `DISABLED`): куртка, шарф, полотенце, картина, цветок, тарелка, кастрюля, стул, скамейка, карандаш. Правило: крупный предмет узнаётся реже 80% (при ≥8 фото) или карандаш 0% на мелких кадрах.
Повторный прогон всех 3913 фото, 64 активных задания, 1825 крупных положительных фото, 233 566 отрицательных пар:
- крупные предметы: **97,2%** (было 90,3%); макро по 40 заданиям с ≥8 фото 97,6%; ложных засчитываний **2,9%** (было 3,2%);
- по местам: кухня 94% (8 заданий), комната 97% (8), школа 99% (9), ванная 96% (9), прихожая 96% (8), еда 98% (10), двор 98% (12);
- слабее всего: тостер 80%, машина 88%, кровать 89%, ванна 94%.
Оговорка: слабые задания выбирались по этим же данным, поэтому 97% завышены. Честная оценка на новых фото ближе к 90–93%.
Варианты: убрать из CLIP метки отключённых предметов, ложных больше (3,3% вместо 2,9%), поэтому метки оставлены. Порог CLIP 0,03: узнано 96,8%, ложных 2,2%; 0,05: 96,3% и 1,6%.
